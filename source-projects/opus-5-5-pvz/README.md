# 植物大战僵尸 · HTML5 同人复刻版

一个用纯 HTML5 Canvas + Web Audio 从零实现的《植物大战僵尸》复刻。
**没有使用任何图片、音频或字体文件**——所有植物、僵尸、场景、界面都由代码逐帧绘制，
所有音效由 Web Audio 实时合成，背景音乐是用内置音序器演奏的原创曲目。

最终产物是一个完全自包含、可离线双击打开的单文件：

```
dist/植物大战僵尸.html   （约 320 KB）
```

### 还原的核心机制
- 阳光经济：天降阳光、向日葵 / 阳光菇产出、卡片冷却
- 伤害分层：手持护盾（报纸 / 铁栅门）→ 头部护具（路障 / 铁桶 / 头盔，三级破损外观）→ 本体（断臂、掉头、倒地）
- 波次导演：按点数预算生成波次，血量削减过半提前出下一波，「一大波僵尸」与「最后一波」提示，黑夜最后一波从墓碑中钻出僵尸
- 割草机 / 泳池清洁车、弹坑、冰道、墓碑、睡莲承载、白天蘑菇睡眠 + 咖啡豆唤醒
- 火炬树桩点燃豌豆（溅射）并解冻寒冰豌豆、磁力菇吸走金属护具、魅惑后的僵尸反戈一击
- 撑杆 / 海豚跳过第一株植物（高坚果可阻挡）、读报僵尸暴怒、舞王召唤伴舞、潜水僵尸水下免疫、冰车碾压并被地刺扎爆、巨人砸扁植物并扔出小鬼
- 浓雾：按格子计算的雾浓度，路灯花照亮、三叶草吹散、闪电瞬间照透；气球僵尸飞越植物（仙人掌 / 三叶草克制）、矿工僵尸从地下绕到后方、跳跳僵尸连续跳跃、小丑僵尸自爆炸毁植物、大蒜让僵尸换行、南瓜头作为外壳保护植物

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标左键 | 选卡、种植、收集阳光、点击按钮 |
| 右键 / Esc | 放下手中的卡片或铲子 |
| 数字键 1-0 | 快速选择对应卡槽 |
| S | 铲子 |
| 空格 / P / Esc | 暂停 / 继续 |
| X | 切换 1× / 2× 速度 |
| F | 全屏 |

> 小游戏在通关 1-5 后解锁，生存模式在通关 1-10 后解锁；也可以在「设置 → 解锁全部内容」中直接体验全部内容。
> 浓雾场景没有天降阳光，开局阳光为 150；气球僵尸飘到房前时，该行的割草机会把它戳下来（每行一次）。

## 开发与构建

```bash
npm install        # 安装 esbuild
npm run dev        # 开发服务器 http://localhost:8940 （直接加载 src/ 下的 ES 模块）
npm run build      # 生成 build/ 中间产物与 dist/植物大战僵尸.html
```

开发模式下（或在任意地址后加 `?debug`）可以在控制台使用 `PVZ` 调试接口：

```js
PVZ.play('2-6')          // 直接进入某关
PVZ.unlockAll()          // 解锁全部
PVZ.sun(1000)            // 加阳光
PVZ.spawn('gargantuar', 2)
await PVZ.bot('1-9')     // 让机器人自动玩一关，检验难度
```

在地址后加 `#gallery` 可以打开美术画廊，一次性浏览全部植物、僵尸与场景。
