# SELENE · 月面漫游

全屏交互式 3D 月面探索网页。探测车、地形、陨石坑、碎石与星空均为实时渲染的三维场景。

## 本地运行

```bash
npm install
npm run dev
```

访问终端显示的本地地址。生成生产版本：`npm run build`。

## 操作

- 左键拖动旋转；滚轮缩放；右键拖动平移。
- 触屏：单指旋转，双指缩放或平移。
- 跟随视角追踪巡航中的探测车；自由探索解除相机跟随。
- 自由探索下，WASD / 方向键移动，Q / E 降低或升高视角。
- 空格暂停或继续；R 重置视角；H 隐藏或显示界面；Esc 关闭指南或恢复界面。
- 速度按钮在 0.5×、1×、2×之间切换。

## 场景

基于 Three.js 的 PBR 材质、动态阴影与金属环境反射。探测车具备六个独立转动的车轮、金属轮刺、悬架、摄影桅杆、天线、采样机械臂、线缆、隔热层与独立太阳能电池。立体月面包含非均匀网格、陨石坑与 4,200 块实例化碎石。轮迹随车辆行驶持续生成。

玉衡号为原创概念探测车，静海边缘地形和所有遥测数据均为程序模拟，并非实际航天任务或地形测绘数据。网页无远程纹理或模型依赖。
