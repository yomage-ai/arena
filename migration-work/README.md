# 候鸟 · MIGRATION

已归档成品是 `results/migration/gpt6-astra-xhigh/import-01/index.html`（相对项目根目录），约 1.04 MiB。直接用现代浏览器打开即可；可以单独复制到任何目录、离线运行，无需服务器、安装或联网。原有庭院项目未改动。

点击「开始迁徙 →」后，鼠标移动或触摸引风。`C` 切换自主镜头，拖拽改变俯仰和偏航，滚轮或双指捏合改变相机距离；自动模式的滚轮观察偏移会在停手两秒后归位。`M` 控制音乐和三层环境声，`P` 控制诗句，`F` 全屏，`H` 说明。

原生 Canvas 2D 完成透视投影、近面裁切、地表分层和空间物体深度排序。每次打开产生新种子；地形按世界坐标生成，沿途分块回收，不把景观重置到起点。暖纸、雾境、暮粉、雪境、夜航每段 8600 单位，锋面宽 2900 单位，横向位置使边缘错落。地理风格、13 段诗和两首音乐遵循各自的轮换规则，整体旅程不按固定视频重复。

30 只鸟使用金角椭圆盘、独立弹簧、相位、幂律胆量和有界分离力；触屏 22 只。16 种命名镜位按六段骨架产生每轮约 100 秒的变奏，每镜 16–17.5 秒；前 48% 保持，后 52% 五次平滑插值到下一镜。高低轮交替，背面与迎面压轴交替，邻镜偏航相差至少 30°。

两首原创音乐《纸上的河流》《远方的窗》各 48 秒，MP3 base64 内嵌；完整播放后交替，曲间 2.4 秒空隙，开场 5 秒淡入。低通风声、窄带河水和高频纸翼由 Web Audio 实时合成。音乐不依赖外部音频文件。

触屏竖屏使用 CSS 顺时针旋转 90°，同时变换输入坐标；Canvas 按设备 DPR 渲染。2200px 起 UI 比例为 1.5，3200px 起为 2。全屏、系统横屏锁定和防息屏会尝试启用；浏览器不提供或拒绝这些 API 时，画面和 CSS 横屏仍可运行。切到后台时旅程与声音暂停，返回后续航。

本目录是制作材料，不是运行依赖：

- `migration.template.html`：全部源码，只有音乐占位符尚未展开。
- `music-1.mp3`、`music-2.mp3`：内嵌音乐的原始成品。
- `compose.py`：标准库合成音乐，制作时用本机 ffmpeg 编码。
- `build.py`：标准库展开 base64，生成最终单文件。
- `check.cjs`：无依赖地理、相机连续性、弹簧稳定性和封装检查。
- `*-check.cjs`：制作环境的 Chromium 无头浏览器验收脚本，使用本机已有测试工具；测试库不进入成品。

在项目根目录重新打包：`python3 migration-work/build.py`，输出到 `artifacts/builds/migration/index.html`，不会覆盖已归档的测评原件。核心检查：`node migration-work/check.cjs`。截图与验证记录位于 `artifacts/migration/`。
