# 候鸟 · MIGRATION 验收记录

成品：`候鸟-MIGRATION.html`。验证环境：本机 Chrome 的无头 Chromium，桌面 1440px、触屏竖屏 390 × 844 / DPR 3、大屏 2400px 和 3300px。浏览器插件连接因本机原生组件签名失败，桌面捕捉也不可用，因此界面验收使用独立无头浏览器；没有把测试库或外部资源加入作品。

- 封装：一个 HTML，两个真实 MP3 base64，无脚本、字体、图片、音频外链。HTTP 验收期间请求只有 HTML 本身；`file://` + 离线模式也成功启动、解码并播放。
- 核心：五种地理气候、锋面颜色连续性、100 轮镜头规则与端点连续性、强风下 180 秒独立弹簧模拟、不同地址和种子的地形差异，全部通过。
- 实时画面：桌面 100 帧样本为 60.10 FPS。五种起飞地点截图已检查；修复了夜航 UI 文字继承问题和低机位天空雾遮暗鸟群的问题。最终低机位仍有 30 只可见纸鸟，星星和窗灯正常呈现。
- 长途：使用真实更新、生成、排序和渲染代码，驱动 240 秒旅程，跨越两轮镜头边界及暖纸→雾境→暮粉锋面；每个检查点均为 30 只可见鸟，有限数值正常，地形缓存保持 27 块，没有随旅程增长。
- 交互：自动/自主切换、拖拽俯仰偏航、滚轮实际距离缩放、风引航、诗句和音乐按钮、说明弹层均通过。触屏竖屏为 CSS 旋转横向，22 只鸟、3 倍 DPR；真实双触点捏合将相机距离从约 1435.79 改至 879.08。
- 音频：两首音乐各 48 秒；第一首实际结束于 AudioContext 48.1387 秒，第二首安排于 50.5387 秒，间隔 2.4000 秒。静音开关和环境声图正常运行，无解码错误。
- 大屏：2400px 的 UI 倍率 1.5，3300px 为 2。
- 控制台：所有验收页面均无 JavaScript 错误，最终语法检查通过。

系统能力边界：实际手机硬件的横屏锁定和防息屏权限未做真机验证；这些 API 的可用性取决于浏览器。作品会进行能力检测和失败回退，不影响 CSS 横屏、输入和离线运行。

详细机器记录见同目录的 `core-checks.json`、`browser-report.json`、`journey-report.json`、`interaction-report.json` 与 `build-info.json`。
