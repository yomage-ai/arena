## 修复记录

首次画面测试发现初始演示角色的动画相位 0 被当作空值，导致渐变坐标不是有限数。已使用空值合并修复，并在实际预览中复查。

预览浏览器在切换视口时出现静态 Canvas 缩略图丢失，因此种子卡和图鉴肖像改为运行时生成的内嵌 PNG 图像。游戏场景仍使用实时 Canvas。最终 8 张卡片图像均完整加载。

修正了短窗口高度计算、卡片标题位置、手机开始按钮换行及横屏底栏裁切。

## 验证边界

画面与交互验收使用本地 HTTP 预览。自动化预览环境不允许直接访问 file URL，未通过该环境直接打开本地文件。打包测试已确认最终 HTML 的脚本、样式和绘图完全内联，无 fetch、CDN、外部字体或模块加载依赖。无需预览服务即可作为独立 HTML 分发。

六波通关、失败、特殊植物与无尽增长由独立引擎测试覆盖；其中一项测试在正常阳光收入与冷却限制下自动布阵并完成冒险通关。
